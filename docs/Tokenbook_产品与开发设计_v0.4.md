# Tokenbook《词元之书》产品与开发设计 v0.4

日期：2026-09-14。状态：整合评审稿，包含已确认的产品方向和补全的工程设计；不表示游戏已实现。

依据：用户提供的《Tokenbook_游戏设计与开发文档_v0.3.md》、2026-09-09 桌面接入探测，以及本任务中逐项确认的决定。冲突时采用用户最新确认：简单教学、少任务、休闲挂机、治愈陪伴。

阅读入口：第 1–9 节说明玩家体验和功能；第 10–14 节说明实现边界；第 15–17 节说明交付和验收。数值标为“试算”或“目标”的均需要原型验证，不是性能实测或最终平衡承诺。

## 1. 产品定义与取舍

Tokenbook 是可公开分发的本地单机像素挂机游戏，首发 macOS。玩家看小人生活，偶尔安排种植或探索，慢慢修复农场。Codex 桌面端的实际使用带来额外学习灵感。

已确认的产品决定：

| 项目 | 决定 |
| --- | --- |
| 工作入口 | 使用官方 Codex 桌面端；Tokenbook 不接管对话和审批 |
| 产品构成 | Godot 游戏应用＋可选 Codex 插件，统一安装引导 |
| 游戏界面 | 所有游戏操作在同一个原生游戏窗口内完成；无网页游戏面板 |
| 运行方式 | 本地单机，无 Tokenbook 账号、云存档、遥测与联网经济 |
| 窗口 | 常驻、可拖动；Codex 失焦、最小化或退出不使其消失 |
| 折叠态 | B：约 240×210 逻辑像素，场景＋今日用量和下一智慧状态丝带 |
| 展开态 | A：约 420×520 逻辑像素，同窗向左上展开，优先保持右下角锚点 |
| 美术 | A：暖木田园，局部青绿灵感微光 |
| 音乐 | 仅治愈轻盈背景音乐，默认开启、音量滑杆约 15%；无操作和通知音效 |
| 新手 | 种一次、学一次、出发一次，目标 3–5 分钟进入自由安排 |
| 任务 | 无每日、每周、签到、限时、接取交付链和常驻任务列表 |

一条新增功能的准入标准：它是否带来一个有趣而轻松的选择，且玩家离开后不需要补救错过的点击？若只增加填表、领红点、重复次数或上线压力，就不进入首版。

首版不做联机、交易、排行榜、转生清档、随机强化失败、装备耐久、专精洗点、即时战斗操作或自动生成剧情。后续六地区世界观保留为内容蓝图，不作为首版交付范围。

## 2. 产品外壳和交互

### 2.1 桌宠与横屏农场（2026-09-19 更新）

折叠态为透明、无边框的单马尾女主角桌宠，不显示农场缩略图、外层卡片或按钮条。首轮只表现休闲、蹲身徒手挖土、收手起身，自动自然往返；陪伴动画不驱动农场奖励或虚构 Codex 工作状态。透明轮廓外允许鼠标穿透，人物可点击、可拖动，拖动不得误触展开。

点击人物进入约 960×600 的横屏农场，画面铺满窗口。农场、背包、主书、小屋、资源和设置均在画面内；菜单覆盖在场景上方。桌宠与农场共享应用、人物进度和存档，同时仅显示一种形态。当前实现复用同一原生窗口并分开视图，避免重复进程和存档写入者。

桌宠和游戏窗口分别记住位置。桌宠置顶且不抢键盘焦点；展开的游戏窗口正常获取焦点，不强制置顶。窗口按当前显示器可用空间缩放和夹紧，农场维持横屏比例，场景两轴等比缩放，不拉伸人物或房屋。macOS Spaces、全屏、Stage Manager、多屏和缩放仍需按实际设备验收。

### 2.2 生命周期

农场内的“−”“×”回到桌宠，不退出应用。Esc 先关闭菜单，再回到桌宠。游戏标题区可拖动，桌宠位置不随游戏窗口移动而改变。

“隐藏到菜单栏”停止绘制，菜单栏叶子恢复；小屋中的“保存并退出”结束应用、音乐与采集进程。初次启动显示桌宠，不抢输入焦点。退出后的游戏进度在下次启动按时间补算，不能宣称退出进程仍在运行。

Codex 不运行时仍可单机游玩。开机启动保持为关闭的可选设置；状态更新不自动打开游戏或跳转 Codex。

### 2.3 简洁操作

常用入口只展示“播种”“收获并续种”“出发”“学会”等直接动作。补给预算、战技优先级、批量销售保留规则放入高级设置。界面始终显示失败的具体原因；后台诊断码不进入日常游戏文案。

## 3. 极简新手和自然成长

首次启动生成默认角色名并保存系统时区，后续可改。主书和免费研究自动启用。用一句话介绍农场，不展示长问卷、插件安装向导或连续剧情弹窗。

| 步骤 | 玩家动作 | 自动处理与固定保障 |
| --- | --- | --- |
| 种一次 | 选择教学播种 | 一批教学种子和足量水已备好；播种后安排 1 分钟安全训练，作物约 3 分钟生长 |
| 学一次 | 收获并打开主书 | 训练提供木剑、手册和 1 点；收获提供木铲、手册和 1 点；同页分别点击“收录并学习”，每项清楚显示 1 点消耗 |
| 出发一次 | 确认探索旧地窖 | 默认装备和稳妥策略已备好，提供一次性基础补给；不等待常规作物成熟 |

三个步骤是体验阶段，不要求只有三次鼠标点击。自动训练属于预先展示的教学安排，玩家可取消或稍后继续。取消后教学卡保留“继续训练”，不会丢失奖励资格。

引导可以随时收起，不锁整个界面。F01/C01 学会前保护两点教程余额及对应实物；其他节点可预览，不能抢先花掉入门保障点。教学物品使用独立保护栏，奖励按唯一里程碑原子入账。跳过引导文字不跳过奖励，也不自动替用户花智慧。

第一次远征开始后结束主动教学。强化、战技、灌溉首次出现时只显示一条可关闭说明，之后可在主书查阅。Codex 连接长期放在主书入口，用户自主启用。

自然成长只保留三个叙事节点：安顿农场、首次探索旧地窖、恢复水闸。奖励随行为发生自动记录；材料修复是玩家主动建设操作，不需要接任务、交任务或领取奖励。NPC 是商店、建筑和短故事入口，不设置好感度日课。

## 4. 游戏时钟、角色和行动安排

### 4.1 一个人与独立生产

角色同一时间只能劳动、制作、取水、建设、训练、远征或休息中的一种。作物生长、已启动的独立机器和研究可以并行。多个 Codex 任务不复制游戏时钟或角色。

角色状态为在家空闲、执行劳动、远征中、返家、恢复中；具体动作保存在行动记录。玩家点击收获时若正在远征，则显示“已安排，返家后收获”。背包整理、出售未锁物品、收录和学习不占角色主动时间。

生活资源保留生命、体力、饱腹和水分，但默认交给补给预设管理。家中安全休息免费恢复，不持续制造饥渴，也不产出可出售的免费物资。缺补给时停止危险行动，回家恢复。异常首版只有中毒，安全恢复可清除，不因玩家数日缺席生病。

角色等级来自实际游戏行动；五属性按配置随等级自动成长，首版没有手动加属性点。熟练度只记录行为，不能在 UI 操作中增加；不引入另一条必须刷满的成长树。

### 4.2 行动安排

界面使用“接下来做什么”表达队列，默认只突出当前和下一项。首版最多安排 5 项；重复次数属于一项远征配置，不复制五十个队列条目。

每项保存 actionId、类型、剩余工作量、所需物资、结束条件和策略版本。排队时只预估，开始时重新验证、扣除或预留资源；预留与库存不能同时被其他操作消费。当前遭遇只能申请撤退，尚未开始的动作可移除或调整顺序。

阻塞动作停在原位并显示原因，不偷偷跳过；玩家可以跳过或重排。自动恢复只是明确允许的内部行动，成功恢复后重新检查原动作，失败不无限重试。

### 4.3 统一时间结算

规则按下一次动作完成、作物成熟、战斗行动、设施产出推进，不由渲染帧驱动。在线拆成小步与离线一次推进，应得到同一状态和随机结果。

普通离线最多补算 24 小时；研究独立最多补算 7 天。超额时长连同收益、饥渴、伤害一起舍弃。游戏模拟游标只前进允许的时长，现实游标推进到此次恢复时刻，不能下次再补领被舍弃时间。

进程运行时使用单调计时；休眠或关闭恢复时根据现实间隔结算。时钟回退不倒扣、不回退已保存游标，也不能让前台实际经过的时间再次计入之后的离线区间。恢复结算分批保存，未完成时暂停玩家写命令并显示进度。

同一时刻事件使用固定优先序与稳定 ID 排序；资源先完成当前事件扣付、再生成产物、再启动依赖动作。Codex 输入不得改变游戏事件顺序或随机数序列。

返回摘要只陈述已发生的收益、消耗、实际补算时长和停止原因；无需点击领奖，不要求逐页确认。短时切换没有重要变化时不弹摘要。

## 5. 农场、加工与经济

### 5.1 农田与作物

地块主状态：未开垦、空地、生长中、成熟。缺水、满仓等作为阻塞原因，不再同时持久化“成熟”和“等待收获”两个同义状态。

开局 4 块空地，木铲可扩至 8 块；扩地直接显示金币/材料和劳动时间。硬土等后续地形不作为首版可操作内容。

| 作物 | 试算时间 | 功能 |
| --- | --- | --- |
| 教学作物 | 3 分钟，仅一次 | 入门收获及初始金币 |
| 萝卜 | 1 小时 | 短周期收入和基础食物 |
| 小麦 | 4 小时 | 面包和稳定补给 |
| 土豆 | 8 小时 | 炖菜与低频安排 |
| 浆果 | 首次 12 小时，复收 8 小时 | 长期种植，最多暂存 2 轮 |

播种先检查种子和整轮用水，缺任一资源不扣款、不建批次。一次性作物成熟后保留；浆果储满两轮后暂停结实，不积累无限欠产。灌溉帮助从储水供水，不凭空生成水。

收获按完整地块产量检查容量，首版不把同一地块拆成多次部分收获。批量操作可逐地成功并返回逐地结果；每地都有独立幂等键。满仓的地块继续保留，其他不受影响地块可收获。

“收获并续种”仅执行一次，收获成功但无种子或水时保留收成并停止续种。不得默认建立无限自动收菜；角色还需按玩家安排执行劳动。缺席不腐烂、不倒扣。

### 5.2 设施

首版定义 8 类设施/入口：住处与床、水源、储水桶、仓库、炉灶、工作台、铁砧、小型灌溉。工作台与铁砧可共用一个场景工坊，避免挤占空间。

住处、床和水源初始可用；炉灶与基础工作台在入门后可直接建造；铁砧随旧地窖首通开放；灌溉是学习 F05 后的可选效率建设。每个入口直接显示条件，无 NPC 往返任务。

配方声明是手工持续劳动还是投入后独立运行。首版取水、建设、工具制作占角色时间；炉灶需角色短时备料点火，烹煮独立推进。物资投入、取消退款和产出容量在配方中明确：未启动可取消且不扣资源；已投入只保留进度，不能取消返还原料再保留产物。

### 5.3 经济规则

金币来自作物和普通探索物资；支出为种子、补给、装备、设施和强化。智慧不可出售或购买。加工允许通过劳动/时间提高价值，不用“加工不得盈利”限制经营；禁止零时间无风险的买入—加工—回收循环。

默认出售是主动操作。可选自动出售只支持普通作物及指定普通材料，遵守锁定量、下一轮种子、自用补给和任务/修复材料保留。装备、技能书和稀有物不默认自动卖。

自动购买默认关闭；开启时必须有每轮预算、整次预算和金币保留额，任一上限耗尽即停止。出发界面默认只提供补给摘要，高级预算可展开。

初版仓库容量、作物价格和配方产量须在 M2 前落成同一套内容表并跑可达性模拟。目标是一天看 2–3 次的玩家也有稳定收入，短周期作物不能在净收益和省心程度上同时全面占优。

## 6. 自动探索与装备

### 6.1 日常入口

选择地点后默认展示“稳妥探索”、推荐装备和可执行轮数，点击出发即可。只在高级设置中配置战技顺序、治疗阈值、补给种类和预算。推荐只检查已知事实，不伪造精确胜率。

训练场无风险；旧地窖承担入门和普通材料；水闸提供正式首领、浆果种源和进阶知识。普通副本试算 10–20 分钟，训练 2–5 分钟；教学训练 1 分钟。首次远征必须有稳定通过的基础配置路径，不靠随机书或额外 Codex 点数。

### 6.2 遭遇规则

每个遭遇冻结属性、装备、技能、补给策略、规则版本和随机状态；实际消耗库存按事务处理，快照不是另一份可重复使用的库存。中途改装下一场才生效，被当前或明确排队引用的装备锁定。

战斗采用固定行动时间线：到达行动时刻，结算到期异常/效果和胜负，再按治疗、撤退、防御、辅助、攻击优先级选择当前可执行行动。敌人按自己的行动时间行动，不机械保证玩家每次都先手。格挡作为满足条件的防御反应单独定义，不能因治疗占掉回合而产生无法解释的防御消失。

蓄力攻击需在可反应时间之前给出预告。基础攻击不占战技栏，额外战技栏 3 个。试算治疗阈值 50%；低于 25% 且无可用治疗时请求撤退。撤退在合法行动边界执行，默认策略需防止一次普通攻击跨越全部保护区间。

伤害、命中上下限、护甲公式、治疗冷却、行动间隔和随机算法统一由带版本的战斗规则定义，并在 M3 以固定种子批量模拟校准。表现动画不得调用结算用随机源。

### 6.3 胜败与重复

完成的房间立即结算一次，未完成房间不奖励。正常撤退保留已完成战利品；战败救援返家，已用补给不返还，装备和角色不永久消失。返家安全恢复，默认首次战败停止重复。

副本最大掉落体积应可由一次远征暂存区容纳。暂存区满则在安全房间边界停止；入库失败时保留物资并禁止再次出发，不丢弃掉落。每轮开始前重新检查资源、预算、容量、次数和撤退请求。

### 6.4 装备与长期收藏

首版武器、上装、一个戒指槽，工具独立。约 8 件有不同用途的装备，主要普通/改良和少量稀有。+1 至 +5 强化保证成功，保存实际投入材料和金币；拆解返还强化材料 80%，按材料向下取整，金币不返，基础拆解另计且不能重复。

主线所需物品首通必得。可选稀有采用随机掉落加定向兑换，试算每完整通关 1 印记、12 印记兑换指定稀有；不显示“必须刷 12 次”任务，不阻塞水闸恢复。

战报默认只显示结果、收获、消耗、停止原因。关键格挡/治疗等记录可展开。用事实解释失败，不自动修改玩家配置，也不指责玩家没有上线。

## 7. 主书、知识与智慧

主书唯一永久存在；技能书是实物；技能页是永久知识。普通流程为获得实物、收录、满足条件学习、配置或生效。入门两页可将收录和学习合并为一次明确确认的事务。

知识只保存 recorded/learned；未发现由不存在的条目表达。“可学习”即时计算。重复书不重复收录、发点或叠加，可主动出售。基础技术永久有效；战技免费换装、不退款；专精不进首版。

学习检查页面、前置、工具、章节和余额；工具只需持有。条件失败无部分扣费；commandId 重试返回原结果。F01/C01 之外不保留刷次数门槛，实际实践计数作为记录和后续可选玩法的依据。

智慧来源：入门 2 点、旧地窖首通 1 点、研究每 24 小时 1 点、Codex 每固定七天最多额外 6 点。其他首版里程碑不隐式再发智慧，避免内容表外发点。研究自动启用、不占角色、不受装备/INT/Token 倍率影响，保存小时余量。

未连接 Codex 学满十节点所需额外智慧为 16 点，可由研究逐步获得；学满不是通关目标。水闸恢复只需要首通获得的维修材料和一次建设劳动，不能要求先学 F05。浆果与自动灌溉属于后续选择，因此不会用数日研究挡住第一章结果。

主书包含技能页、技能树、词元记录、图鉴、故事。默认列表按“已拥有、可学习、已学会”整理；只展示紧邻已知知识的依赖，不让整棵未解锁树充满问号。可以标记一个学习目标，但不催促、不自动花点。

## 8. 轻叙事和首版内容

世界仍是失去稳定季节的四时网。玩家从试验田发现古书，在旧地窖找到水闸线索，逐步恢复当地供水。叙事没有毁灭倒计时，不因离线倒退。

首版主要变化：住处亮灯、田地扩展、水闸恢复、浆果种下。每次变化用环境和一两句对白表达，详细档案留在主书。木匠、商人、种子守护者、水闸维护者可作为 4 个轻量角色，不各自展开支线树。

修复水闸后重复探索是侧区回收或训练，不再把已修复地区写成重新被破坏。玩家可以停留种田、收集装备、优化搭配，游戏不要求继续刷章节。

内容预算：一个农场/住处、4 至 8 块田、教学加 4 种常规作物、8 类设施入口、训练场、两个副本、一个正式首领、10 个技能节点、约 8 件装备、2 种工具、少量配方、一组治愈音乐。设施数量以本表为准，修正早先“7 个”与枚举不一致的问题。

## 9. 视觉与音乐制作规范

主配色为暖木、鼠尾草绿、柔和天蓝、羊皮纸。遗迹局部降低亮度并用青绿色表达古代设施。危险用图标和文字配合砖红色，不持续闪烁。

基础瓦片 16×16，角色基准 32×40，图标 16×16/24×24，边框按 8 像素网格制作；以原型可读性决定最终资源尺寸并冻结图集规格。世界使用最近邻、像素对齐和整数放大；UI 中文用清晰字体，不能为了像素风牺牲小字号阅读。

窗口尺寸是逻辑点，图集尺寸是素材像素，不能直接混为一谈。折叠/展开通过重新布局与改变场景可见范围完成，不将整张画面非整数拉伸；正文三档字号以分页/滚动重新布局。放大窗口过程中可先调整外壳，再淡入重新布局的内容，避免每帧缩放导致闪烁。

MVP 动画包括待机、行走、播种、取水、收获、开垦、睡眠、剑击、格挡、重击、受击、治疗、撤退/救援和阅读。待机 4–6 帧/秒、劳动 6–8、战斗 8–12 为素材播放试算；与应用渲染上限、规则时间分别管理。

Codex 工作状态只影响书页微光和提示，角色位置始终来自游戏行动。镜头切换不复制角色；可查看农场，但正在远征的角色不在农场中活动。

音乐默认音量滑杆 15%，淡入启动；这是增益设置，不保证所有音源相同听感，制作时需统一响度。采用一组 3–5 分钟柔和循环素材，首尾衔接，切场景不频繁换曲。收获、攻击、点击、智慧到账、工作通知不播放音效。窗口失焦或收起继续音乐，隐藏默认继续，完全退出停止；提供始终可达的静音按钮。

美术、音乐和字体都记录作者、来源、许可及再分发范围。浏览器方案图中的 emoji 只是布局占位，不作为正式角色资产。首版不调用模型即时生成剧情或音乐。

## 10. Codex 接入与计量边界

### 10.1 三条通道

| 通道 | 用途 | 限制 |
| --- | --- | --- |
| Hooks 生命周期 | 显示已提交、运行、需要输入及可确认终态 | 不发智慧；提交不等于真实开始 |
| 本地 rollout 数值适配 | 唯一精确奖励来源 | 内部格式、按具体版本验证；不分析文字 |
| App Server 账户用量 | 用户主动诊断时可选读取 | 账户范围不同，不与本机记录强制相等，不补差额发奖 |

所有能力检查按实际字段映射，不承诺每个 Hook 都含 turnId/父子关系。缺稳定回合 ID 的事件只能更新会话级提示，不能虚构完整回合历史。Stop 若不能证明最终结束，只显示已观察停止，等待可信终态或保留未知。

工作执行状态与通知是否已查看是两个字段。清除提示不能把 completed 改成 archived，也不表示工作验收。SessionEnd 不自动代表任务成功；超时只转 unknown，不伪造 completed。

### 10.2 连接范围

连接由用户主动启用，覆盖此 Mac 的已验证 Codex 桌面来源。首次连接记录文件基线和可靠时间，不导入此前历史、不追溯发奖。已存在且继续追加的会话也可纳入新记录；必须保存基线累计才能对账，不能要求“连接后增量＝整个线程累计”。

停用连接保存截止时间和文件游标，停用期间不采集。恢复时开启新连接区间；游戏关闭但连接仍启用时，后续可补读启用区间内保留的数值记录。文件已被清理则明确表示缺失。

主游戏离线可玩。Codex 本身正常联网不属于 Tokenbook 上传数据；可选账户诊断会调用 Codex 服务，必须在入口说明并由用户触发。默认游戏路径不依赖网络、API Key 或账户用量接口。

### 10.3 生产适配器

专用随应用打包的本地适配器增量读取 metadata 与数值字段，不复制原始会话。JSON 的类型需结构化验证，不能用字符串含有 token_usage_record 就认定数值行。格式解码不可避免接触文件字节，但无关字段在提取边界丢弃；不能宣称操作系统授予的是“仅 Token 访问权”。

适配器输出 ID、版本、可信时间、来源范围、数值、规范化版本和文件游标令牌。游戏验证后在事务中记录接受/隔离结果与游标，确认后适配器前进；崩溃重发仍去重。半行等待完整，坏行记录偏移和错误码，不把全文写到 rejected 日志。

不跟随会话目录外的符号链接。路径仅在本机私有游标中保存，诊断导出替换为哈希。限制单条记录大小，超限显示该来源待核对，不无限占内存。

2026-09-09 探针覆盖 136 个历史文件，其中 7 个具有精细记录并通过数值累计检查。这不是整个 0.148.x/0.151.x/0.153.x 版本族的兼容证明；发布白名单只列端到端实际验证过的具体构建和 schema。旧探针是 M0 工具，不直接作为生产适配器。

未知版本或数值冲突暂停受影响来源的新奖励，保留其他已验证来源和独立研究。来源累计包含子任务但无法证明范围时，隔离相互重叠部分；不得仅凭父/子标签一起相加。响应唯一键与归属规则共同保证去重，累计记录只对账，不再作为第二份增量。

## 11. 用量账本和智慧奖励

总已记录用量＝输入＋输出。缓存输入是输入子集；计入灵感＝输入−缓存输入＋输出；已包含在输出内的推理不重复加。字段缺失不是零：总量可信可先展示，灵感待核对，日归属与奖励归属独立标记。

周期从存档创建 UTC 时间起每 604800 秒一个区间，包含左边界、不含右边界。连接、花点、统计时区或模型变化不重置周期。试算规则 T0=10000、每周期最多 6 点，六个累计门槛固定为 4143、10000、18285、30000、46569、70000。运行时用同一整数门槛表判断发点和显示下一点，避免浮点 log/ceil 在边界不一致。

入账事务同时完成唯一响应、日期汇总、奖励周期累计、唯一发奖交易、余额和读取游标。发点键为 saveId＋periodIndex＋ruleVersion＋pointOrdinal。大报告跨多个门槛一次补齐，查看动画或页面不领奖。

日期按存档统计时区和可信来源时间分组，时区变更可重建日汇总，不能改变周期归属或余额。跨周期汇总无法拆分时保持待核对；不能把收到时间充当发生时间。总日汇总加日期待核对量应等于累计已记录量。

迟到报告回原周期补发尚未发的差额。达到上限后仍计总用量，但溢出不转下周期。更正规则从下周期生效，旧周期沿用旧规则。来源纠错先隔离争议数据，不把已消费智慧扣成负数。

词元记录展示今日、累计、明细、覆盖起点、下一个门槛、周期已发/6、钱包、研究进度和最后同步时间。未连接/待同步/不支持是明确状态，不能显示成零。完整版本信息和错误码放到诊断页。

不提供 Token 排行榜、用量催促、截止冲刺或工作价值评价。默认下一点只平静显示差额，不提示“再发一个请求”。

## 12. 软件模块与本地通信

技术方向为 Godot＋GDScript 游戏规则与原生 UI、SQLite 持久化、独立 Codex 插件。此前确认的 Godot 4.7.2 是候选锁定版本，开工时需验证实际可取得的正式构建、导出模板及原生扩展兼容性后锁版本，不能仅凭方案中的版本号视为验证完成。

```text
game/                  Godot 场景、规则、模拟、视图与内容
native/storage/        SQLite 适配与必要原生能力
integrations/          Codex 插件、Hook 转发与数值适配器
contracts/             版本化 JSON Schema 与合成夹具
tools/                 内容校验、模拟、构建与打包
docs/                  产品规格、技术决定和测试证据
```

模块边界：domain 提供规则计算，不依赖场景树或数据库；application 接收命令并控制事务；simulation 调度事件；persistence 提供有限的状态写入与账本 API；presentation 从提交后的版本化快照刷新 UI；adapter 只输出事实、不改游戏状态。

只有游戏应用写存档 SQLite，第二实例唤醒第一实例后退出。SQLite 原生模块采用 GDExtension 路线；先验证维护中的绑定或小范围自有封装，锁定源码、许可证、两种架构构建和崩溃恢复测试，不提前声称 SQLite 是 Godot 内置能力。

### 12.1 Hook 收件箱

插件 Hook 只过滤允许字段、写临时 JSON、关闭文件并原子改名为 .event。游戏通过文件通知唤醒并定期低频补扫，处理后按唯一 eventId 提交，再删除已处理文件；删除前崩溃只导致重复投递，不重复交易。

生产路径：Application Support/Tokenbook 下的 inbox、state、saves、backups、diagnostics；目录 700、文件 600。临时文件和最终文件位于同目录。要求普通文件、正确所有者、大小上限、协议版本与有限字段；拒绝路径穿越和符号链接。隔离记录只保留安全字段/哈希，不保留未知正文。

收件箱设容量上限，初始目标 10 MiB；满时 Hook 快速退出并记录可合并的丢弃计数，不阻塞 Codex，不无限重试。生命周期丢失只能标未知；用量恢复依赖独立数值记录，不能用丢失的 Hook 推算。

短时游戏未运行时可暂存生命周期，但游戏被手动退出后 Hook 不自行启动窗口。只由明确的“打开 Tokenbook”命令或用户手动启动恢复。status.json 为只读脱敏快照，包含发布时间、进程会话和有效期限；过期显示未知，不能把旧状态当实时。

TypeScript 是插件开发选项，不要求玩家安装 Node/npm。发布包应包含独立可执行转发器/适配器或受控内置运行时；构建时打包，安装时不联网编译、不拉依赖。游戏和插件共用事件协议，不强求共用编程语言。

首版不开放 localhost HTTP 端口。文件权限隔离其他用户，但不声称能抵抗同一系统用户手动篡改；这是本地单机，无需引入在线防作弊。

## 13. 存档、一致性与恢复

每个命令带 commandId、saveId、类型、参数和预期状态版本。成功事务包括资源校验、消耗/产物、状态改变、唯一业务记录和命令结果。重复命令返回既有结果；相同 ID 不同参数拒绝，不能误当重试。

核心实体：SaveMetadata、PlayerState、InventoryStack、ItemInstance、KnowledgeEntry、MasteryCounter、FarmPlot/CropBatch、ActionQueue、Expedition/EncounterSnapshot、ProcessedCommand、WorkTurn、UsageRecord、RewardPeriod、RewardTransaction、AdapterCursor。金币/智慧用整数，Token 使用能覆盖大累计的整数表示，跨 JSON 边界必要时十进制字符串，拒绝静默精度损失。

SQLite 由单写者管理外键、事务、唯一约束和 schema 迁移；拟启用 WAL 与同步保护，具体参数由写入延迟和崩溃注入测试确认。UI 不持有另一份权威钱包。日汇总可重建，奖励/消费流水和命令幂等键不可因清日志一起删除。

每次命令和遭遇/房间关键结算原子保存，长任务按检查点保存规则状态、随机游标和模拟时间。规则计算先在工作副本进行，持久化成功后发布新状态；失败回到最后提交版本，暂停受影响操作，避免内存显示已中奖但磁盘未记录。

### 13.1 备份与迁移

拟保留最近 3 次正常恢复点及最近 7 天每日备份，创建后校验再轮换。迁移前额外留一份不可被本次轮换覆盖的备份。通过一致性备份 API 生成，不直接复制打开的数据库主文件或忽略 WAL。

迁移在副本上完成并检验结构、余额、唯一记录和引用，再切换活动文件；失败保留原档并提供恢复/导出。降级应用遇到较新 schema 只读拒写，不自动回退迁移。

### 13.2 导出、导入、多个存档

默认一个活动世界；创建新世界和恢复旧世界放在设置深处，不鼓励刷档。只有活动世界推进及接收新启用区间，旧档时间冻结；恢复备份是恢复同一世界，不制造新的历史奖励来源。

导出为带版本和校验值的存档包，包含游戏状态及维持幂等所需最小账本，不含 Codex 原文、本机绝对路径或绑定凭据。首版普通存档即可，不承诺数据库静态加密；导出前说明含游戏进度和用量统计。

导入先做容量、格式、版本和内容引用检查，在临时位置验证后才允许替换。不要直接运行导入数据库的视图、触发器或未知 SQL；从白名单数据读入全新受控 schema。替换前保存当前恢复点。

导入/切档暂停采集并切换 saveBindingId。历史重复用量不能重新投递到新世界；跨绑定区间无法证明归属的记录待核对。换机器导入保留游戏与旧统计，新机器由重新连接建立新来源。

“断开连接”保留已得智慧；“清除用量统计”删除明细与相关缓存并重建采集起点，保留明确告知的最小奖励幂等记录，防止重扫再次发点。若用户要求彻底删除关联数据，则停止原连接并重新建立未来区间，不能从旧历史重新发奖。重置整个世界是独立的可撤销前备份操作，执行时需明确确认具体存档。

## 14. 性能和分发

以下是验收目标，不是现有测量：Apple Silicon 基准机器上折叠态渲染上限 24 FPS、展开通常 30 FPS、可选 60 FPS；静止无变化停止重绘；后台隐藏停止渲染；事件模拟与音乐独立运行。Compatibility 为优先候选渲染器，透明边缘和 macOS GPU 表现由原型对比后固定。

初始性能预算：折叠常驻 30 分钟平均 CPU 不超过单个逻辑核心的 3%，整体进程常驻内存目标 200 MiB 内；点击关键反馈 100ms 内；窗口展开约 200ms；最大普通离线场景 24h 结算目标 2 秒内。记录机器、构建、渲染器、窗口模式和测量口径；不达标时优先降重绘、减少轮询、分批处理，再调整目标并说明依据。

公开发布为已签名、公证的 macOS 安装包，目标 macOS 13+；Apple Silicon 与 Intel 仅在各自测试后声明支持。开发机跑通不能替代旧系统或 Intel 真机验收。所选引擎若不支持最低系统，需在发布前明确调整，不静默扩大承诺。

首次使用可离线进入游戏。可选 Codex 连接时检测已安装桌面端、适配版本、插件加载和 Hook 信任；用户自己确认具体 Hook 信任，不静默修改现有 Hooks。应用升级不替用户放宽授权。

安装引导可以共用，但 macOS 安装和 Codex 插件授信仍是不同步骤，不能承诺所有机器“一键零确认”。不要求玩家使用终端。卸载插件不删游戏；卸载应用默认保留存档，应用内提供明确清理入口。

首版不后台自动联网检查更新；用户可主动查看版本发布页或手动安装新签名包。更新先备份再迁移。签名、公证、依赖与素材许可证、隐私说明、恢复说明在公开分发前准备齐全；开发者证书由发布者提供，不向玩家索要。

## 15. 开发顺序与阶段交付

每阶段结束交付可运行构建和对应证据，完成文档不等于完成阶段。先验证会影响整体选型的原生窗口、存储与插件接入，再逐步加内容。

| 阶段 | 交付范围 | 出阶段标准 |
| --- | --- | --- |
| M0 补完 | Godot 悬浮/原位展开、多屏/焦点、SQLite 往返、打包桥接、真实 Hook 冒烟 | 用真实 macOS 应用证明关键窗口行为；具体引擎构建和 Codex 构建可复现；无强制 iframe 验收 |
| M1 最小可玩 | 一个角色、教学种植、木铲/木剑、学习快捷操作、首个自动遭遇、存档/恢复 | 无 Codex 可 3–5 分钟开始探索；重启不重复得物或花点；无需战斗点击 |
| M2 农场与成长 | 四种常规作物、扩地、必要设施/加工、十节点、研究 | 一天低频操作仍可持续；没有接交任务或刷次数门槛；学习条件图可达 |
| M3 探索内容 | 两副本、首领、补给/撤退、8 件装备、强化/兑换、水闸恢复 | 基础路线可恢复水闸；战败可恢复；随机与离线等价；无 F05 前置锁死 |
| M4 真实联动 | 数值适配、来源范围验证、账本、周期、词元页和轻提示 | 真实桌面数据＋合成异常测试通过；父子、重复、迟到不多发；不支持能降级 |
| M5 陪伴打磨 | 暖木像素资产、主书 UI、轻音乐、多屏/字号、合并摘要、性能优化 | 真机长时间常驻不抢焦点；像素/文字清晰；音乐可静音；性能预算有记录 |
| M6 本地公开测试 | 签名包、离线安装、插件可选安装、迁移/备份/导入、使用说明 | 干净系统无需开发工具；断网可玩；声明平台全部验证；用户可自主恢复 |

M0 的插件端到端测试应在安装后新开的 Codex 任务中进行。测试动作由用户授权后执行；本设计任务本身不安装插件、不启用全局 Hook、不创建新任务或发布构建。

## 17. 相对旧稿的明确修订与证据边界

| 旧方向/歧义 | v0.4 决定 |
| --- | --- |
| 九步教学与任务链 | 三阶段体验；进度内部记账，不呈现任务列表 |
| 三次常规收获/三次地窖 | 首次相关体验发现知识，不刷次数解锁基础功能 |
| 建造灌溉才算第一章完成 | 恢复水闸即可；F05 灌溉是后续效率选择 |
| Tauri/Pixi/网页或 iframe 主界面 | Godot 游戏原生 UI，插件只辅助连接 |
| 账户累计用于补足本机用量 | 范围不同，仅可选诊断，不强制相等或发差额 |
| Hook 提交即任务真实开始 | 只报告来源能证明的事实；缺回合能力就会话级显示 |
| 清通知等于 archived 工作状态 | 执行状态与通知状态独立 |
| 精细记录出现过即支持版本族 | 只承诺验证过的具体构建，包含范围另需证明 |
| 每次随机抽取立即单独落盘 | 在事务/检查点原子保存结果和随机状态，避免高频碎写 |
| 存档不复制配置但快照需要稳定 | 普通状态引用 ID；进行中遭遇保存所需冻结数值及规则版本 |
| 常规操作音效 | 全部去掉，只保留轻盈背景音乐 |
