## 本轮解决的兼容问题

1. Godot 窗口尺寸使用物理像素；macOS 当前实现按最大屏幕 backing scale 换算。窗口尺寸和 UI 逻辑布局分别设置，不能直接把 240 写成 Retina 窗口的物理宽度。
2. Godot 主窗口不能直接 `Window.hide()`。增加极小的 AppKit GDExtension，对本进程 NSWindow 执行 `orderOut` / `orderFrontRegardless`，并查询真实 `isVisible`；隐藏时关闭渲染循环，菜单栏入口保留。
3. 本机系统字体路径加载曾导致 FreeType 错误。改为随项目携带 OFL 授权的 Noto Sans SC；以数字 OpenType 标签选择正常字重，避免变量字体默认极细字重。
4. Godot 导入命令可能在脚本错误时仍返回 0。开发启动脚本额外识别脚本/资源错误，自动测试设超时，防止挂住后误报通过。
