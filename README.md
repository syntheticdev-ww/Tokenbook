# Tokenbook · 词元之书

本地单机、低打扰的田园挂机游戏，作为 Codex 桌面端的独立伴随窗口。

**换电脑或没有聊天上下文时，先读 [开发交接说明](DEVELOPMENT_HANDOFF.md)**：包含当前分支、安装步骤、素材版本、验收状态、代码入口和下一步工作。可携带的关键画面与验证记录位于 `docs/handoff/2026-09-22/`。

目前是 **农场可玩版 0.1**，不是完整 v0.4 游戏。已将确认的像素美术拆成场景、角色、作物和小猫，接入真实玩法：八块田（四块已开垦）、人物沿田间路劳动、种植与收获、买种子与出售、主书学习开垦、离线成长、轻柔循环背景音乐和 SQLite 自动存档。

场景已改为斜侧俯视的 2.5D 布局：八块菱形田沿两条斜轴排布，小路连接门廊，人物和作物按前后位置遮挡。仍沿用原先确认的精细像素画风、红瓦小楼、河流石桥、角色与小猫；参考截图只提供布局方向，没有用于生成画风或 UI。布局改变不重排存档中的地块和作物。

角色使用完整人物的前斜向与后斜向两组八帧慢步、八个浇水姿势和八个采集姿势；已撤回分层拉腿实验。起步先转向、走完一步再站定劳动，两套图集按固定比例匹配人物高度；劳动分准备、保持、收势。动作随距离推进，展开收起或切换游戏页面不会重播。作物轻微随风、河面局部微光、水滴从壶嘴落下，没有新增音效。行走和劳动最高 60 FPS，静置 24 FPS、隐藏 12 FPS；左右仍为镜像，并非完整手绘八向动画，交替迈腿的素材细节仍需精修。

尚未连接 Codex，不读会话、不显示模拟 Token；远征、训练、完整知识与装备系统、正式玩家安装包仍待开发。没有每日任务、操作音效或自动出售。

## 本机试玩

双击仓库里的 `启动Tokenbook.command`，或在此目录运行：

```sh
npm run game
```

启动后是透明的单马尾女主角桌宠，休闲与徒手挖土自动交替；桌宠动作只作陪伴，不会凭空发放农场收益。点击人物打开 1120×740 横屏农场，拖动人物移动桌宠。透明空白区域不拦截桌面点击。农场内的 `−`、`×` 或农场页的 `Esc` 返回桌宠；小屋里的“保存并退出”结束应用。

农场画面铺满窗口；构图纵向轻微收扁 6%，取景继续向小屋靠拢，减少河景占比，保留八块田和小屋。背景、田地、角色、阴影与点击位置使用同一投影。横屏背景使用 `farm-background-landscape-v3.png`：保留屋瓦、石墙和远景的清晰像素细节，草地降低亮黄和饱和度，以长短、方向及疏密有变化的草叶替换重复的波浪状草簇，整体按物理像素网格显示。树叶和草丛动态通过移动采样位置保留素材原色，避免相邻颜色混合造成模糊；水面仍保留微光。背包、主书、小屋和操作按钮都在画面内。背包等菜单覆盖在农场上方，`Esc` 或点击菜单外侧先返回农场。拖动顶部标题区移动游戏窗口，桌宠位置独立保留。游戏窗口正常获取焦点，桌宠置顶但不抢键盘焦点。

新档选一块田、点击播种开始：人物劳动 12 秒，第一株初春萝卜再长 3 分钟。普通萝卜 / 小麦 / 土豆分别长 1 / 4 / 8 小时；成熟一直保留。人物一次做一件事，最多等待五项。小屋买种子、取水、调音乐和取消排队，背包出售收成，主书学习开垦；进度全部本地保存。

小屋“隐藏到菜单栏”暂停绘制，点击菜单栏叶子恢复。离线成长最多结算 24 小时，自然研究最多 7 天；每满 24 小时获得 1 点智慧。

试玩档保存在项目私有 `.runtime/m0/`，与未来正式版隔离。不要在游戏运行时直接编辑数据库。重复启动当前只会拒绝第二实例，使用原窗口或菜单栏恢复。

旧单田试玩档首次升级前自动生成 `world.db.pre-farm-v1.sqlite` 一致性备份，保留原来的收获数量、田里作物的生长时间和窗口位置。异常存档停止写入，不会覆盖成新档。备份恢复界面尚未实现；遇到异常先保留整个数据目录。

### 新人物实景接入测试

运行 `npm run game:character-preview`，先显示桌宠，点击进入横屏农场；每次新建独立临时存档，不影响原农场。点击第一块田或“走到第一块田”体验现有单马尾角色起走、行走和收步，支持停止、继续与重试。

该预览仍只开放“小屋 → 第一块田”正向路线，背向、转身和完整劳动衔接尚未接入。桌宠的徒手挖土是新独立动画；不把它冒充已接入农场的劳动控制器。`npm run game` 保留原来的完整可玩流程与存档。

v25 重绘动作因人物粗糙、嘴部细节丢失和行走闪动的反馈已撤出运行入口；素材保留作为历史实验。常规预览恢复 v24 行走与 desktop-pet-v1，冻结现有帧、1.05 秒周期及起停控制，不宣称原有步态问题已解决。

当前静态素材为 `game/assets/art/gardener-v57/idle.png`：在 v56 基础上，将领口内不明显的浅色阴影改为更易辨认的暖色阶梯像素块，用短 Y 形明暗表现轻微饱满感，保留现有领口覆盖、肤色、脸型、脖长与整体像素网格。生成素材可能包含目标区域外的细微差异，本次局部修整仍待用户视觉确认。背景沿用自然草地 v3；只更新静态人物素材与实景预览，未接入行走或桌宠动画，v39 动作实验仍保持撤回状态。

运行 `npm run game:material-preview` 打开 v57 独立静态实景预览，使用临时存档，关闭按钮可退出。图一底稿为 1154×1363 的竖向画布，因此人物画布改为 80×94 逻辑像素、160×188 原生网格，避免沿用旧横向画布把人物拉宽；轮廓高约 90.5 逻辑像素，与此前 v56 的高度相差不到 0.2%。图像宽高比因整数网格取整误差约 0.5%，鞋底注册到原站位。脸与身体共用 (0.25, 0.25) 采样位置，Retina 按 1:1 原生网格显示，普通屏固定间隔选择同一组原生像素。没有脸部局部滤镜、模糊或颜色混合，窗口、场景坐标和动作控制未变。

`npm run game:material-test` 以实际 80×94 和 160×188 画布验证原图色值、透明边缘、双眼亮点与嘴部色块，五官检查区域随新画布坐标调整。检查普通屏是否精确选择 Retina 原生像素、真实场景的站位高度和背景原色，以及人物区域之外的逐像素一致性。当前证据位于 `artifacts/character-reference-v57/pixel-grid/`：`comparison.png` 左 v56、右 v57；`after-scene.png` 为全景，两版使用同一 v3 背景。`neckline-comparison.png` 为领口及上衣局部对照，左 v56、右 v57，以同一网格整数放大。`npm run game:environment-test` 验证场景动态。检查通过只代表渲染和范围正确，不等同于审美验收。

验证命令：`npm run game:pet-test`（桌宠、透明轮廓、窗口切换和菜单）、`npm run game:character-test`（角色步态）、`npm run game:smoke`（真实种植收获流程）、`npm run game:environment-test`（场景动态）。新画面证据在 `artifacts/desktop-pet-v1/`。

## 开发环境

当前准备脚本仅支持 macOS，需要 Node.js 22+ 与 Apple Command Line Tools（`clang`）。正式玩家安装包尚未制作，未来不会要求这些开发工具。

```sh
npm run game:setup  # 下载并校验项目私有 Godot / SQLite，编译原生窗口模块
npm test           # 原有数值探针 + 原创背景音乐格式 / 循环测试
npm run game:test  # 无界面的农场 / 布局 / SQLite 行为测试，使用临时目录
npm run game:smoke # 显示真实窗口，实测劳动计时、交互和窗口行为并截图
npm run game:music # 从源代码重新生成项目自有的 64 秒循环音乐
```

准备脚本不修改 `/Applications`、全局 Git 身份、Codex 配置或 Hooks。不关闭 Gatekeeper，不索取辅助功能或屏幕录制权限。首次需联网下载，准备好后游戏运行不依赖网络。

截图与测试输出位于 `artifacts/m0/`；自动测试数据位于系统生成的 `tokenbook-m0-*` 临时目录。下载运行时、生成库、缓存、个人存档和常规测试输出不纳入 Git；用于跨电脑交接的精选画面与脱敏验证记录保存在 `docs/handoff/2026-09-22/`。

## 代码入口

- `game/main.gd`：原生窗口生命周期、共享游戏状态与音乐。
- `game/game_overlay.gd`：横屏场景内的导航、操作和菜单。
- `game/desktop_pet.gd`：透明桌宠、完整人物动作帧和轮廓点击区域。
- `game/farm_view.gd`：分层像素场景、角色动作、作物阶段与点击反馈。
- `game/farm_motion.gd`：连续移动、距离驱动步态与劳动动作；不控制资源或奖励。
- `game/farm_geometry.gd`：地块形状、田外工作点与田间路线。
- `game/farm_rules.gd`：纯游戏规则、劳动队列和在线 / 离线结算。
- `game/farm_store.gd`：农场事务、命令去重、存档验证与旧档备份升级。
- `game/window_layout.gd`：尺寸和边缘夹紧计算。
- `game/save_store.gd`：保留旧试玩档兼容与窗口位置存储。
- `game/assets/art/README.md`：内置图像生成工具制作的素材、分格与提示词规格。
- `scripts/ambient-music.mjs`：无外部采样的原创背景音乐生成器。
- `native/macos/window_bridge.m`：只操作本进程窗口的 AppKit 扩展。
- `scripts/game.mjs`：锁定依赖、启动与验证。

完整方向见 [产品与开发设计 v0.4](docs/Tokenbook_产品与开发设计_v0.4.md)，已测结果和未完成边界见 [M0 原生试玩记录](docs/m0-native-prototype.md)。依赖许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。
