# Tokenbook · 词元之书

本地单机、低打扰的田园挂机游戏，作为 Codex 桌面端的独立伴随窗口。

目前是 **农场可玩版 0.1**，不是完整 v0.4 游戏。已将确认的像素美术拆成场景、角色、作物和小猫，接入真实玩法：八块田（四块已开垦）、人物沿田间路劳动、种植与收获、买种子与出售、主书学习开垦、离线成长、轻柔循环背景音乐和 SQLite 自动存档。

场景已改为斜侧俯视的 2.5D 布局：八块菱形田沿两条斜轴排布，小路连接门廊，人物和作物按前后位置遮挡。仍沿用原先确认的精细像素画风、红瓦小楼、河流石桥、角色与小猫；参考截图只提供布局方向，没有用于生成画风或 UI。布局改变不重排存档中的地块和作物。

角色使用完整人物的前斜向与后斜向两组八帧慢步、八个浇水姿势和八个采集姿势；已撤回分层拉腿实验。起步先转向、走完一步再站定劳动，两套图集按固定比例匹配人物高度；劳动分准备、保持、收势。动作随距离推进，展开收起或切换游戏页面不会重播。作物轻微随风、河面局部微光、水滴从壶嘴落下，没有新增音效。行走和劳动最高 60 FPS，静置 24 FPS、隐藏 12 FPS；左右仍为镜像，并非完整手绘八向动画，交替迈腿的素材细节仍需精修。

尚未连接 Codex，不读会话、不显示模拟 Token；远征、训练、完整知识与装备系统、正式玩家安装包仍待开发。没有每日任务、操作音效或自动出售。

## 本机试玩

双击仓库里的 `启动Tokenbook.command`，或在此目录运行：

```sh
npm run game
```

点击小院或右上角 `+` 原位展开。新档点一块田、点击播种即可开始：人物劳动 12 秒，第一株初春萝卜再长 3 分钟，成熟后点击收获。第一份收获后，到“主书”学习木铲耕作，就能开垦其余田地。

常规萝卜 / 小麦 / 土豆分别长 1 / 4 / 8 小时；成熟一直保留。点击田地选择目标，底部按钮安排劳动；人物一次做一件事，最多等待五项，种子和水只在开始时扣除。缺水可到“小屋”免费取水，会优先补水再继续等待的工作。“背包”出售收成，“小屋”买种子、调音乐和取消未开始的安排，全部操作留在同一个游戏窗口里。

拖动标题区移动；`−` / “收起陪伴”收起；`×` 保存退出。`Esc` 先回农场，再收起。`♪` 切换静音。“隐藏到菜单栏”后，点击菜单栏叶子恢复；不会因切换 Codex 任务自动消失。普通离线成长最多结算 24 小时，自然研究最多 7 天；每满 24 小时获得 1 点智慧。

试玩档保存在项目私有 `.runtime/m0/`，与未来正式版隔离。不要在游戏运行时直接编辑数据库。重复启动当前只会拒绝第二实例，使用原窗口或菜单栏恢复。

旧单田试玩档首次升级前自动生成 `world.db.pre-farm-v1.sqlite` 一致性备份，保留原来的收获数量、田里作物的生长时间和窗口位置。异常存档停止写入，不会覆盖成新档。备份恢复界面尚未实现；遇到异常先保留整个数据目录。

## 开发环境

当前准备脚本仅支持 macOS，需要 Node.js 22+ 与 Apple Command Line Tools（`clang`）。正式玩家安装包尚未制作，未来不会要求这些开发工具。

```sh
npm run game:setup  # 下载并校验项目私有 Godot / SQLite，编译原生窗口模块
npm test           # 原有数值探针 + 原创背景音乐格式 / 循环测试
npm run game:test  # 无界面的农场 / 布局 / SQLite 行为测试，使用临时目录
npm run game:smoke # 显示真实窗口，实测劳动计时、交互和窗口行为并截图
npm run game:music # 从源代码重新生成项目自有的 64 秒循环音乐
```

准备脚本不修改 `/Applications`、全局 Git 身份、Codex 配置或 Hooks。不关闭 Gatekeeper，不索取辅助功能或屏幕录制权限。首次需联网下载，准备好后游戏运行不依赖网络。

截图与测试输出位于 `artifacts/m0/`；自动测试数据位于系统生成的 `tokenbook-m0-*` 临时目录。下载运行时、生成库、缓存、个人存档和截图均不纳入 Git。

## 代码入口

- `game/main.gd`：原生窗口生命周期、游戏 UI 与音乐。
- `game/farm_view.gd`：分层像素场景、角色动作、作物阶段与点击反馈。
- `game/farm_motion.gd`：连续移动、距离驱动步态与劳动动作；不控制资源或奖励。
- `game/farm_geometry.gd`：地块形状、田外工作点与田间路线。
- `game/farm_rules.gd`：纯游戏规则、劳动队列和在线 / 离线结算。
- `game/farm_store.gd`：农场事务、命令去重、存档验证与旧档备份升级。
- `game/window_layout.gd`：尺寸和边缘夹紧计算。
- `game/save_store.gd`：保留旧试玩档兼容与窗口位置存储。
- `game/assets/art/README.md`：内置图像生成工具制作的素材、分格与提示词规格。
- `scripts/ambient-music.mjs`：无外部采样的原创背景音乐生成器。
- `native/macos/window_bridge.m`：只操作本进程窗口的 AppKit 扩展。
- `scripts/game.mjs`：锁定依赖、启动与验证。

完整方向见 [产品与开发设计 v0.4](docs/Tokenbook_产品与开发设计_v0.4.md)，已测结果和未完成边界见 [M0 原生试玩记录](docs/m0-native-prototype.md)。依赖许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。
